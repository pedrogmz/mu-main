# Kryon theme

Generated by `generate_theme.py` from `tokens.json` and the `handmade/` folder beside it. Do not
edit these files here: change `tokens.json` or `handmade/` and run the generator again (also after
pulling a new MuMain, so the theme picks up changes to the `modern` stylesheets).

- `theme.ini`: inherits `modern` (its .rml forks and any file not written here) and
  loads the fonts named in `tokens.json`.
- `tokens.ini`: 104 tokens with this palette (the base theme's names plus this theme's own `kryon-*`).
- 117 `.rcss` files: the `modern` stylesheets with their literal colors retinted.
  Where `handmade/` has a stylesheet of the same name, it is appended, so its rules win while the
  layout keeps following `modern`; `base.rcss` gets the shared Kryon kit this way.
- Copied from `handmade/` as they are: `fonts/Gelasio-Bold.ttf`, `fonts/Gelasio-Regular.ttf`, `fonts/OFL.txt`, `icons/chat_alpha.OZT`, `icons/chat_frame.OZT`, `icons/chat_gens.OZT`, `icons/chat_guild.OZT`, `icons/chat_log.OZT`, `icons/chat_normal.OZT`, `icons/chat_party.OZT`, `icons/chat_size.OZT`, `icons/chat_system.OZT`, `icons/chat_whisper.OZT`, `icons/chevron_left.OZT`, `icons/chevron_right.OZT`, `icons/close.OZT`, `icons/coin.OZT`, `icons/crown.OZT`, `icons/expand.OZT`, `icons/gift.OZT`, `icons/grip.OZT`, `icons/master.OZT`, `icons/maximize.OZT`, `icons/minimize.OZT`, `icons/pet.OZT`, `icons/plus.OZT`, `icons/quest.OZT`, `icons/refresh.OZT`, `icons/repair.OZT`, `icons/restore.OZT`, `icons/shop.OZT`.

Select it with `$theme kryon` in chat, in Options > UI > Theme, or `[UI] RmlTheme=kryon` in config.ini.
